# AutoWorld

A responsive multi-page website for a fictional car dealership, built with HTML, CSS and Bootstrap 5.

## Team
- Yerassyl Aldebayev - Home and Models pages
- Temirlan Tatken - Services and About pages

## Pages
- `index.html` - Home: hero, popular categories, featured vehicles
- `models.html` - Models: comparison table, features, image carousel
- `services.html` - Services: info sidebar and test drive booking form
- `about.html` - About: core values and team

## Live site
https://Era-UX.github.io/cars-project/

## Technologies
- HTML5
- CSS3 (custom media queries for typography and image sizing)
- Bootstrap 5.3 (loaded from CDN): grid, navbar, cards, carousel, table, form, buttons
