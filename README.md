# AutoWorld

A responsive multi-page website for a fictional car dealership, built with HTML5, CSS3, Bootstrap 5, and JavaScript (ES6).

## Team
- Yerassyl Aldebayev - Home (`index.html`, `js/popup.js`, `js/background.js`) and Models (`models.html`, `js/accordion.js`)
- Temirlan Tatken - Services (`services.html`, `js/validation.js`) and About (`about.html`, `js/datetime.js`)

## Pages & JavaScript Features
- **index.html** - Home: hero, categories, featured vehicles, popup subscription form (Task 3), background color switcher (Task 4)
- **models.html** - Models: comparison table, standard features, image carousel, FAQ accordion (Task 2)
- **services.html** - Services: info sidebar, test drive form, account registration form with JS validation (Task 1)
- **about.html** - About: core values, team profiles, live showroom date and time display (Task 5)

## Live site
https://Era-UX.github.io/cars-project/

## Technologies
- HTML5
- CSS3 (custom media queries, transitions, popup and accordion styling)
- Bootstrap 5.3 (loaded from CDN)
- Vanilla JavaScript ES6 (DOM manipulation, event listeners, form validation, Date API)
